# Code of Conduct

This project is a shared space for learning, building, and improving the portfolio template.

## Expectations

- Be respectful and constructive.
- Keep feedback focused on the code, content, or design.
- Assume good intent and communicate clearly.
- Help others learn when you can.

## Unacceptable Behavior

- Harassment, intimidation, or abuse
- Hate speech or discriminatory language
- Personal attacks or inflammatory behavior
- Disruptive conduct that makes collaboration harder

## Scope

This code of conduct applies to repository discussions, issues, pull requests, and any contribution related to this project.

## Enforcement

Maintainers may remove or decline contributions that violate this code of conduct.

## Contact

If something feels off or you need help, open an issue or reach out through the repository discussion flow.
